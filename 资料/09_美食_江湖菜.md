## 一、老甘家小龙虾江湖菜（连续6年大众点评必吃榜）

### 基础信息
- 总店地址：江北区洋河中路91号（近观音桥）
- 评分：4.5/5，大众点评重庆美食人气榜第一
- 人均：80-120元
- 日常排队：中午11点持续到深夜2点
- 五一期间单日排队超5000桌

### 必点菜
| 菜品 | 说明 |
|------|------|
| 麻辣小龙虾 | 招牌，石柱红辣椒+茂汶花椒，6种花椒3种辣椒 |
| 蒜蓉小龙虾 | 蒜香浓郁 |
| 香辣大肉蟹 | 现捞现杀，蟹肉鲜嫩入味 |
| 铁山坪花椒鸡 | 麻辣鲜香，下饭神器 |
| 秋秋妹耙凤爪 | 一抿就化 |
| 辣卤鸭脑壳 | 能吃辣必点 |
| 爆辣蛙 | 挑战极限辣度 |

### 评价
- "本地朋友带过来的，开好多年的老字号"
- "虾子个头实在，剥开肉饱满弹牙，花椒香气足"
- "连续6年必吃榜，随便点不踩雷"
- "四个人花了780左右，味道不如从前"（差评）

### 建议
- 提前预约，不然门口排队
- 夏天主营小龙虾，冬天菜品更多（烧烤+鲜货）
- 13家分店，洪崖洞也有店

## 二、曾老幺鱼庄（防空洞火锅+江湖菜）

### 基础信息
- 地址：长江滨江路220号附5号
- 评分：4.5/5（重庆传奇小餐馆排行榜第1名）
- 人均：80-85元
- 营业时间：24小时
- 特色：防空洞餐厅，重庆独有体验

### 必点菜
| 菜品 | 说明 |
|------|------|
| 邮亭鲫鱼（招牌） | 先煎后烧，红油中浸熟，鲜香过瘾 |
| 手抓排骨 | 先炒后炸，酥脆+肉汁+脆骨 |
| 香辣虾 | 油炸+干辣椒爆炒，开背去线 |

### 评价
- "二十多年老店，防空洞环境冬暖夏凉"
- "鲫鱼鲜美，但骨刺多，老人小孩小心"
- "环境简陋，服务态度堪忧，出品才是长盛不衰的原因"
- "午间才是最佳时段，晚间通风差"

## 三、林中乐辣子鸡（歌乐山总店）

### 基础信息
- 地址：歌乐山三百梯黄桷树
- 评分：4.5/5（重庆江湖菜榜第15名）
- 人均：115元
- 营业时间：09:00-21:00
- 特色：重庆辣子鸡发源地

### 必点菜
| 菜品 | 说明 |
|------|------|
| 辣子鸡（招牌） | 农家土鸡，麻味大于辣味，在辣椒里找鸡丁 |
| 泡椒鸡肾 | 酸辣爽脆 |
| 炝炒丝瓜 | 去囊去核，清甜爽口 |

### 评价
- "辣子鸡麻味十足，花椒干海椒的草本香味在红油中激发"
- "上菜两小时后还能找到鸡丁的才能称为真正的辣子鸡"
- "节假日客满不接受预约，建议直接上三楼大厅人少"
- "服务冷漠，卫生条件一般"

## 五、江湖菜避坑
1. 景区附近江湖菜店普遍溢价，味道一般
2. 歌乐山辣子鸡发源地的店更正宗，但环境一般
3. 辣度都很高，不能吃辣提前说
4. 老甘家等热门店建议提前预约，否则排队1-2小时
