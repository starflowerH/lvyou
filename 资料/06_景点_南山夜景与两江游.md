# 南山一棵树 · 云端之眼 · 两江夜游 攻略汇总

## 一、南山一棵树观景台

### 基础信息
- 地址：南岸区龙黄公路（南山公园路101号附近）
- 门票：30元
- 开放时间：09:00-22:30
- 城区探照灯22:00关闭，观看请趁早
- 评分：携程4.3/5（1691条评价）

### 游客真实评价（两极分化）
**好评**：
- "视野绝佳，渝中半岛万家灯火尽收眼底"
- "有凸出玻璃观景阳台，免费高倍望远镜"
- "夜景非常震撼，第一次看会深受震撼"

**差评**：
- "人太多，不值花30块钱去看人，照片拍的都是人"
- "就是个普普通通的观景台，服务设施极差，咖啡厅最低消费48元/位"
- "进来加拍照的时间最多十分钟就转完了"
- "晚上不好打车，堵车很厉害"

### 建议
- 日落前1小时到（约17:30-18:30），拍日落+夜景渐变
- 停车场车位少，纯靠运气
- 看完可顺路逛南滨路、吃泉水鸡
- ⚠️ 人多时体验差，可考虑替代方案

### 替代方案：鹅岭公园瞰胜楼
- 免费登顶，360°无遮挡俯瞰渝中、江北、南岸三区
- 视野比南山一棵树更好，人少免费
- 如果只看一个，推荐瞰胜楼 > 南山一棵树

## 二、云端之眼观景台（2026热门新地标）
- 位于解放碑附近高楼，高空俯瞰两江四岸
- 距长江索道北站步行仅5分钟
- 可与长江索道串联：白天坐索道→云端之眼看全景
- 建议傍晚去，日落+夜景一次搞定

## 三、两江夜游

### 基础信息
- 航线：朝天门→大剧院→洪崖洞→科技馆→两江汇流→南滨路→湖广会馆→东水门大桥
- 航程：约16-20公里
- 时长：约45分钟
- 发船时间：19:30-22:00滚动发班
- 登船码头：
  - 洪崖洞客运码头（经典游）
  - 朝天门7码头（甄选游/臻品游）
  - 朝天门9码头（金碧系列）

### 票价
| 系列 | 优惠价 | 说明 |
|------|--------|------|
| 两江经典游 | 138-158元 | 洪崖洞码头登船 |
| 两江精品游 | 158-188元 | 朝天门7码头 |
| 甄选游 | 188元 | 朝天皓月号/星河号，船更新更大 |
| 金碧系列 | 138-158元 | 朝天门9码头 |
| 儿童 | 1.2米以下免票 | 1.2米以上同成人 |

### Klook游客评价（4.5/5，222条）
- "重庆夜景美得令人窒息，绝对值得一看"
- "建议上船直奔二楼占位看完表演，再上三楼甲板拍照"
- "只需条形码和护照即可顺利进入"
- "多付80元升级VIP区，有专属区域+水果饮料"
- 差评："游览非常短，约40分钟，不太值" "登船过程太混乱"

### 避坑建议
1. 提前30分钟到码头排队，满员可能提前开航
2. 三楼露天甲板免费但座位有限，早去有座
3. 夏天19:30登船时天还没全黑，但有另一番风味
4. 不要相信路边低价游船，无安全保障
5. VIP升级约80-100元，含专属区域+水果饮料，人多时值得
6. 船上可能有摄影师拍照，打印照免费但大尺寸需购买
