## 一、核心认知（本地人视角）
**正宗重庆火锅 = 社区老店 + 手工炒料牛油锅底**
- 本地人反复回购的店：居民楼下、没有华丽装修、手工菜多、价格便宜
- 门口拉客喊"进来坐"的店，99%是预制菜锅底
- 景区火锅价格贵3-5倍，味道一般

## 三、必点菜品与吃法

### 锅底选择
- 第一次来选**微辣**（重庆微辣 ≈ 外地中辣！）
- 吃不了辣选鸳鸯锅（会被本地朋友鄙视）
- 配唯怡豆奶或老荫茶解辣
- 锅底用老鹰茶代替高汤的店，辣度柔和不伤胃

### 必点菜
| 菜品 | 吃法 |
|------|------|
| 鲜毛肚 | 七上八下涮8-10秒，入口脆嫩 |
| 鸭肠 | 快速涮几秒，爽脆 |
| 黄喉 | 脆脆弹弹，越嚼越香 |
| 老肉片/嫩牛肉 | 提前腌制，入味 |
| 卤肥肠/虎皮鸡爪 | 煮到软烂，越啃越香 |
| 薄切腰片 | 涮8秒，蘸干碟 |
| 鲜鸭血 | 牛奶鸭血最嫩 |

### 蘸料
- 正宗吃法：**只加香油+蒜泥+葱花+蚝油**
- 不要加麻酱（重庆火锅不用麻酱）
- 蘑菇咸菜碟（珮姐特色）可中和辣味

### 结尾
- 一碗**红糖冰汤圆**或手工冰粉，冰凉解辣

## 四、避坑清单
1. ❌ 景区门口拉客的火锅店慎入
2. ❌ 出租车司机推荐的店要警惕（有游客被带去空无一人的黑店被收天价）
3. ❌ 点菜时注意：重庆的"微辣"已经很辣，别逞强
4. ❌ 不要点肥牛卷——重庆火锅不认冻品卷，只吃鲜切牛肉
5. ✅ 认准社区店 > 网红店，手工炒料 > 工业化底料
6. ✅ 大众点评搜"社区火锅""居民楼火锅"，看评论里提到"本地人常去""手工菜"的
7. ✅ 工作日晚市或周末中午去，避开高峰
